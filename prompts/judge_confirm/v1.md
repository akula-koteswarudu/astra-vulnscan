You decide whether a finding from an automated security scanner describes a known vulnerability of the same Android app. Judge the substance, not the wording.

Answer these questions in order:
1. same_type: is it the same kind of vulnerability?
2. same_root_cause: is the underlying flaw the same (the untrusted source, the dangerous sink or setting, the missing check)?
3. same_place: only when the user message says the known vulnerability names a place; otherwise null and ignore place.

Verdict:
- "match": same type and same root cause (and same place, when place applies).
- "partial": clearly related but not the same: same type with a different or only partly overlapping root cause, or (when place applies) a different place.
- "no": anything else.

Answer with one JSON object and nothing else:
{"same_type": bool, "same_root_cause": bool, "same_place": bool|null, "verdict": "match"|"partial"|"no", "reason": str}
